- *Mimic* (P4 islands): dormant = plain chest (texture swaps to `mimic_dormant`, yaw grid-snapped, silent, no despawn); wakes when a non-sneaking player comes within 2.5 blocks, opens it, or hits it; hops + bites; sleeps again after 10 s without a target.

- **Sounds:** every custom mob (these five AND shark, crabs, castaway, monkey, merchant, crew, captain — 59 events, ~117 variants) are synthesized by **`tools/gen_mob_sounds.py`** (numpy+scipy DSP → mono Ogg Vorbis via ffmpeg; formant-voice siren, bubble/zap jelly, sub-boom brute, wood-clack mimic, whale-moan angler). It merges its events into `sounds.json` (music preserved) and adds subtitles to the lang file; event ids must match `ModSounds`. Re-run after editing a design.

**World Gen:** 15 biomes across 5 phases; custom BiomeSource; custom noise settings (sea_level=63); spawn island port city (see SPAWN ISLAND section); entity spawns via `ModEntitySpawns`.

**Trees:** every phase has a leafy signature tree + the older bare-trunk trees: P1 shorewood (banana/coconut decorators) + **palm**; P2 **tidewood** (forked trunk, acacia canopy); P3 ashen/burning + **cinder** (charred log, glowing ember leaves); P4 shrouded + **wispwood**; P5 ethereal + **voidbloom**. All baked into biome JSONs via `PixelPiratesBiomes` → `ModConfiguredFeatures`/`ModPlacedFeatures`. Boulders use `Feature.FOREST_ROCK` (LOCAL_MODIFICATIONS step), ground patches use `Feature.DISK` (UNDERGROUND_ORES step), trees VEGETAL_DECORATION. **Keep feature order consistent across biomes sharing a step or the game crashes with "feature order cycle" — new trees always go AFTER existing ones in every builder.**

**Vanilla decoration (2026-09-28): `datagen/biome/VanillaBiomeExtras`.** Every builder ends with `VanillaBiomeExtras.add(generation, placedFeatures, Profile.X)` — seabed disks + the full vanilla ore set everywhere (the dimension previously had NO ores), plus a themed profile: HUB, TROPICAL (jungle grass, melons, cane, warm seagrass/kelp/pickles), OPEN_SEA (seagrass meadows, kelp), REEF (vanilla coral), VOLCANIC (dead bush, lava springs, extra gold), CURSED (ferns, mushrooms, cold kelp), ABYSS (amethyst geodes, glow lichen). Cycle-safe by construction: extras always come after custom features and in the single canonical `ORDER` list; profiles pick a subset, never an order. New vanilla features → append to `ORDER`.
